Primary Memory

Primary memory is memory that is directly accessed by the CPU. It stores the data and instructions the computer needs immediately. The two main forms of primary memory are RAM and ROM.

RAM is temporary and loses its data when the power is turned off, while ROM keeps its contents and stores important startup instructions for the computer.

Types of Primary Memory

RAM

Random Access Memory stores active programs and data currently being used by the CPU.

Dynamic RAM

Common main memory that needs constant refreshing but can store large amounts of data.

Static RAM

Faster and more expensive memory often used in cache.

ROM

Read Only Memory stores permanent instructions such as firmware and boot processes.

What Happens When RAM Is Full

When a computer has too many processes to handle and its RAM is full, the operating system uses virtual memory. Virtual memory is part of secondary storage that acts like extra RAM.

The system moves less active data from RAM to the storage drive to free space. This allows the computer to continue working, but it becomes slower because storage devices are much slower than RAM.

Types of Storage Devices

Magnetic Storage

Includes hard disk drives and magnetic tape. Data is stored using magnetism.

Optical Storage

Includes CDs, DVDs, and Blu ray discs. Lasers are used to read and write data.

Solid State Storage

Includes SSDs, USB flash drives, and memory cards. Data is stored in flash memory chips.

Choosing a Storage Device

Choosing a storage device depends on speed, capacity, durability, portability, reliability, and cost. SSDs are fast and durable, hard drives are cheaper for large storage, and optical discs can be useful for media and backups.

The best choice depends on what the device will be used for. Some users need speed, while others need large storage space or low cost.
